# 实测评估前的训练流程与loss检查图

用途：实验日志检查，不是论文配图。图片只读取原正式训练日志，没有重新训练或替换权重。

## 原数据流程

1. 冻结文件级划分：仿真34条训练记录、738周期；另外15条验证记录、302周期，按原工况分组。仿真Source-Test和实测Final-Holdout不进入本流程。
2. 每轮对整条仿真训练记录逐相按RMS校准高斯噪声。每条记录抽取10/15/20/25/30/35/40 dB中的一档，再使用冻结边界切出完整周期、插值为5×4096输入；加噪早于模型归一化。每个周期有干净、含噪两个配对视图。
3. LP4＋ResNet：0–4阶复谱投影→MD归一化→128点→ResNet。A0：五相共享RMS→512点平均降采样→四层Haar注意力CNN。B0：0–8阶复谐波恢复→MD归一化→128点→ResNet。
4. B0额外先做10轮源域恢复预训练，只更新恢复器，以干净仿真谱为目标。然后三模型各训练50轮，种子42/43/44；Adam学习率0.001，batch=32。分类每批32个原周期，对应64个配对视图；最后一批2个原周期。每轮24次更新。
5. 每轮结束用源验证的Clean及固定0/5/10/20/30 dB版本验证，不反传、不更新参数。六个版本仍是相同15个文件、302周期。
6. 选模：Clean F1距本运行峰值不超过1个百分点；在候选轮次中取五噪声验证F1均值最高者，再按Clean更高、轮次更早处理并列。训练完成50轮后保存源选中best.pt。
7. 冻结权重，再对原88条实测Dev、每条件2474周期推理。实测数据不进入参数训练或权重选择；347条最终保留集未评估。

## loss定义及记录方式

- A0、LP4＋ResNet：0.5×干净视图分类交叉熵＋0.5×含噪视图分类交叉熵。
- B0联合阶段：同上分类损失＋0.2×复谐波恢复损失；恢复损失为按干净公共基波标度归一化的复谱实/虚部Smooth-L1之和。
- B0预训练：只优化上述恢复损失；它的10轮不包含在联合训练50轮横轴内。
- 日志训练loss是24个batch的算术平均，未按每批样本数加权，最后小批量与其他批量权重相同。每轮噪声、顺序也变化。
- 原日志没有逐轮验证loss；主图下排是五档源验证Macro-F1，不是验证loss。
