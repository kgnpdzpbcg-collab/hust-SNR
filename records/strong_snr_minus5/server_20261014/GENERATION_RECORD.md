## 噪声生成方法

**仿真**沿用原5/0 dB方法：每相独立生成高斯噪声，再按整条记录的信号和实际噪声均方功率校准到−5 dB。基础种子仍为20261012；Train/Val/Source-Test及各记录使用原命名随机流规则。Val保留`HUST-V1:val:{snr}:{record_id}`规则。新档位使用其对应的确定随机样本，不宣称与旧0/5 dB仿真噪声为同一随机样本。

**实测**沿用作者干净文件与10 dB文件的配对残差缩放：

```text
noise10 = author_snr10_current - clean_current
current_minus5 = clean_current + noise10 × 10^((10 - (-5))/20)
              = clean_current + noise10 × 5.623413251903491
```

实测−5 dB与原0 dB复用相同作者噪声形态，噪声幅度相对0 dB放大`10^0.25 = 1.778279410038923`倍。新噪声直接从作者10 dB残差构造，没有在已经含噪的0/5 dB波形上另加一层随机噪声；各档位不能视作独立采集。−5 dB表示每相整记录噪声功率约为信号功率的3.162277660168379倍。
