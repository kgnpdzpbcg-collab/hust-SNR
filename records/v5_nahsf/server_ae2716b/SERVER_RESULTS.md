# V5 NA-HSF：服务器三种子实验记录

上游分支：`research/na-hsf-v5`，上游提交`90d268c3fb0ff84080d9d3918d41f8daef875495`；运行提交`ae2716bbcd3dd23a959696b486103ac50efa087d`。

## 配置及执行前接口修正

- 仅训练V5 nahsf：种子42、43、44；每组从随机初始化训练50轮、批量32、Adam学习率0.001、weight_decay=0。
- CNN结构25,620参数，门控3→8→1共41参数，总25,661。CNN和门控均训练；CNN初始化与原V4相同，门控输出初始化为0.5。
- 按V5文档使用原V4噪声协议：仿真训练10/15/20/25/30/35/40 dB，每轮整记录逐相RMS校准高斯噪声；验证Clean及固定10/20/30 dB。0/5 dB不参与训练或选模。
- 损失0.5 CE(Clean)+0.5 CE(noisy)，每模型每轮24次更新，50轮1200次更新，三模型共3600次更新。
- 选模只使用仿真验证集：Clean距本次最高分不超过1个百分点，优先三档噪声平均Macro-F1，再优先Clean和较早轮次。
- 对照为原V4的三阶/四阶低通历史结果，未重新训练控制组，未使用扩大噪声后重训的V4成绩作本轮对照。
- 网络文件v5_nahsf.py保持上游原样。执行前补充两处：历史0/5 dB的snr_db字段兼容读取；评估入口设置原V4严格确定性和关闭TF32。旧JSON没有改写。

## 实际数据

34个仿真MAT训练、15个仿真MAT验证，分别使用原738/302个完整周期。原冻结记录和标签、重复记录处理及周期边界保持不变；每周期插值4096点，NA-HSF后执行MD归一化，再输入五相×128点CNN。

实测评估原88个编号，Clean及10/15/20/25/30/35/40/5/0 dB共10个条件，每条件2474个周期。作者原始10–40 dB文件保持不变；5/0 dB沿用Clean+(作者10dB−Clean)×10**((10−SNR)/20)派生数据，共用原噪声形态。

每条件六类数量：Healthy 1106、OUS(A) 307、OLS(A) 297、OP(A) 298、OUS(A)&OUS(B) 237、OLS(A)&OP(C) 229。10个仿真保留编号与347个实测最终保留编号未评估。

门控输入只有当前五相波形的频谱描述符；实测真实类别只用于评估指标和门控分组统计，不输入模型，不用于选择最佳权重。

具体文件编号及周期数见[SOURCE_RECORDS.csv](SOURCE_RECORDS.csv)、[TARGET_RECORDS.csv](TARGET_RECORDS.csv)。

## 执行与核验

服务器wang@172.28.128.160，RTX 5070 Ti，复用原uv/PyTorch环境。三个种子并行，每进程4条CPU线程。正式训练、评估、配对汇总总耗时25.764761秒；不包含部署、前置检查和独立复核。

- 两个原生smoke入口及36项测试通过，包含真实历史压力测试格式。
- 真实GPU训练批次验证门控末层首步梯度和首层第二步梯度均有限且非零；CNN初值及首轮噪声指纹与原V4一致。
- 三组源验证选模复算通过；最佳权重的12组仿真验证指标重放一致。
- 30组实测预测逐条复现；六类指标、混淆矩阵及健康误报/故障漏报由sklearn独立复算。
- 30组α统计与描述符均值独立复算；60行历史逐种子配对及20组汇总复核通过。
- 1922个旧文件、原输入及旧权重的字节指纹保持不变；3个V5权重和BatchNorm统计量在复核中未改变。
- 最终保留编号未评估；全部三个种子均保留。原始电流、MAT、权重和环境未上传。
