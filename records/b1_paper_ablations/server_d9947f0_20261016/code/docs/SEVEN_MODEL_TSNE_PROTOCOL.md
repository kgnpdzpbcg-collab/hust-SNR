# 七模型单种子编码特征可视化

用户要求仅绘制V5效果最好的一个种子。固定展示选择规则为：在六模型与本轮ResNet共同具备的42/43/44中，计算已有V5在实测Dev的Clean、10、5、0 dB四个条件等权平均Macro-F1，最高者用于所有七个模型的展示；并列时取较小种子。该规则只选展示种子，不改变源验证选中的权重或三种子正式成绩。

本次选择是利用Dev结果的事后展示选择，不能解释成随机代表种子、三种子均值、独立测试或稳定性证据。记录所有候选分数和选择规则；旧三种子图保留，不替换历史记录。

模型为A′无滤波、LP3、LP4、固定α=0.5、V5、Xu-Full和ResNet1D。前六模型提取原352维编码器输出；ResNet提取其全局平均池化后的128维向量，恰为六类Linear分类器的输入。ResNet没有50维隐藏层，不添加新层、不提取六类logits。只绘制编码特征主图，不额外生成不存在的ResNet 50维表示。

每条件读取原88个Dev编号全部2474个周期，Clean/10/5/0 dB共享原周期边界与顺序，不删点、均衡抽样或移动标签。目标0/5 dB来自已有作者10 dB噪声残差放大数据，不是新采集的实测记录。原始输入、MD归一化和滤波均与各模型正式预测一致。

无标签全局RMS标量变换→PCA50→固定t-SNE；参数和二维高斯初始化与上一轮六模型可视化完全一致。六模型所选种子的Clean/10 dB投影原样复用，新增其0/5 dB及ResNet四条件共16组投影；共28组、四张七面板图。各组独立拟合，坐标位置和绝对簇间距离不能跨面板比较。

原空间宏平均轮廓系数、排除同一原始文件的5NN同类率、可信度和实际分类Macro-F1均保存。不同模型原生特征维度不同；几何统计用于整体表示对照，不表示训练算法、特征维度或单模块消融完全相同。图中颜色是实际标签，F1来自原分类器。特征提取前后模型状态须相同，原分类头重放预测须逐项匹配。
