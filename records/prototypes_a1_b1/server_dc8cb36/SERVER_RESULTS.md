## 与历史实验的协议差异

- A1/B1选模：干净Val Macro-F1在峰值1个百分点范围内，依次最大化五噪声平均F1、干净F1；F1完全并列时最小化五噪声平均交叉熵，最后选较早轮次。
- 历史A0/B0/LP4相同F1条件下直接选较早轮次，没有CE平局判据。下表同时包含模型、目标函数和选模更新，不能作为只改变网络结构的消融。
- B0为k0..8恢复、5通道ResNet和0.2倍恢复损失；B1为k0..4收缩、10通道双视图ResNet及新的复谱/相强度/噪声标定恢复目标，恢复权重1。
- 历史结果按原正式best保存，不用epoch50诊断成绩替换，不重训历史模型。冻结配置中的提交前pending备注保留原字节；运行完成状态以本记录及RUN_STATUS为准。
