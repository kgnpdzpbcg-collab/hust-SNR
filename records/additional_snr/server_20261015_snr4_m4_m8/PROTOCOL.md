# 4/−4/−8 dB固定权重与特征可视化协议

用户于2026-10-15指定在已有测试之外新增4、−4、−8 dB，使用新划分训练的42/44种子最佳权重评价，再绘制对应t-SNE。模型为ResNet＋LP4、Plain CNN1D、ResNet1D、B1。

## 三步顺序

1. 数据：只对固定88个实测Dev编号生成三档共264个MAT，再独立核验保存后的文件、原输入SHA、实际SNR及残差缩放。原最终Holdout不读取。
2. 评价：复用原4728e9b训练的8份best，不训练、不微调、不改选epoch；24组预测保存后再加载权重独立重放，重算六类指标。
3. 特征图：前两步passed后提取原六分类Linear输入的128维GAP向量；分类头logits及原预测逐项核对后，用上一轮完全相同参数投影。每档两行42/44、四列LP4/CNN/ResNet/B1，三张600dpi PNG及字体嵌入PDF。

## 噪声规则

`I_new = I_clean + (I_author10 − I_clean) × 10^((10 − target_dB)/20)`。

复用原`scaled_author_current`，先确认作者参考整记录逐相SNR为10 dB。不添加另一份高斯噪声，不修改时间及转速列，MAT仍为10031×7的float64、I_noisy字段。4/−4/−8的噪声倍数约1.995262/5.011872/7.943282。SNR按整记录计算，不表示每个周期或故障段均精确为同一dB。

三档复用同一作者噪声残差，不是独立采集或独立噪声实现。每档同2474个原周期，真实标签/顺序及原模型预处理不变。新数据、评价、投影及图片单独保存，既有五档图片及六种子结果不覆盖。

配置为`configs/additional_snr4_minus4_minus8_v1.json`。数据/评价入口`additional_snr_fixed_weights.py`；特征图入口复用`source_cycle_tsne.py`，仅受控扩展配置条件、输入目录和组数，原模型算法不改。服务器沿用原uv；本地沿用已有绘图库，不安装依赖。
