# 四模型：训练10–40 dB、验证增加0/5 dB的服务器实验记录

运行代码提交：`56513c7b37ec990ac1a3aa060ed9b453e8dd7e5d`。协议：`four_models_train10_40_val0_5_10_20_30_v1`。

## 配置

- 模型：A′无滤波(identity)、A′+三阶低通(lowpass3)、A′+四阶低通(lowpass4)、V5 NA-HSF(nahsf)。CNN均为原25,620参数；NA-HSF额外41参数。
- 四模型×三个种子42/43/44，全部从原随机初始化训练50轮，batch32，Adam lr=0.001，weight_decay=0。
- 训练噪声仍为10/15/20/25/30/35/40 dB，每轮整条仿真记录逐相RMS校准高斯噪声；没有将0/5 dB加入训练。
- 验证Clean以及0/5/10/20/30 dB；新增0/5 dB直接读取此前核验的固定仿真MAT。
- 分类损失0.5 CE(Clean)+0.5 CE(noisy)。每轮24次更新，每模型50轮共1200次，全部12模型共14400次。
- 五档噪声验证Macro-F1平均值用于选模；Clean仍须距本次最高分不超过1个百分点，分数相同时优先Clean，再优先较早轮次。
- 四模型使用统一训练循环。原模型实现、归一化、切周期和训练噪声随机流均未修改。
- 另保存旧三档选模规则对应的审计快照，以便核对原训练；该快照不用于本轮实测评估，也不新增训练。

## 数据文件与处理

34个仿真MAT训练、15个仿真MAT验证，分别使用原738/302个完整周期。0/5 dB仿真验证文件各15个，共30个，字段I_We。具体文件编号和各类周期数见SOURCE_RECORDS.csv。
训练每批使用对应Clean和noisy周期；验证纯推理，不修改模型或BatchNorm状态。原始周期插值4096点，再按各模型执行无滤波/低通/NA-HSF，统一MD归一化并重采样为五相×128点CNN输入。

实测使用原88个编号、每条件2474个周期，评估Clean及10/15/20/25/30/35/40/5/0 dB共10个条件、120组结果。5/0 dB沿用作者10 dB噪声放大派生的数据，未重抽噪声。编号见TARGET_RECORDS.csv。
每条件类别数量：Healthy 1106、OUS(A) 307、OLS(A) 297、OP(A) 298、OUS(A)&OUS(B) 237、OLS(A)&OP(C) 229。原10个仿真保留编号、347个实测最终保留编号未评估；实测标签不参与训练或选模。

## 执行及独立核验

服务器wang@172.28.128.160，RTX 5070 Ti；复用原uv/PyTorch环境。四模型并行，每进程四条CPU线程。正式训练、实测评估及汇总总耗时56.445242秒，不包含部署、前置测试和独立复核。

- 41项测试通过；CNN初始化、模型实现和首轮训练噪声与旧实验相同；固定0/5 dB验证文件匹配原随机流。
- 600轮训练loss、原Clean和10/20/30 dB验证分数逐数值相同；旧规则对应的12份审计权重与原最佳权重逐张量相同。
- 新五档仿真选模独立复算通过；12个最佳权重对应72组仿真验证指标重放一致。
- 120组实测预测逐条重放一致，sklearn独立复算六类指标及混淆矩阵；30组NA-HSF门控统计重放一致。
- 40组跨种子成绩及60组模型间配对复核通过。
- 1235个共享输入和旧结果/权重的字节指纹保持不变，本轮评估也未修改12个模型的参数及BatchNorm统计量。
- 本轮实测成绩仅来自五档验证选中的best.pt，旧规则审计快照未用于本轮实测测试。
- 最终保留编号未评估；原始电流、MAT、正式/审计权重和环境未提交。
