## 配置与数据

服务器GPU：NVIDIA GeForce RTX 5070 Ti；Python 3.12.3，PyTorch 2.14.1+cu130，NumPy 2.5.3。复用原uv/PyTorch环境，没有新建环境或安装依赖。三种方法各使用一个并发进程，每进程4个CPU线程；严格确定性运行，关闭TF32。

- Source-Train：34条记录、738个周期；Source-Val：15条记录、302个周期，沿用Gate0/V1冻结划分。
- Target-Dev：88条唯一记录、2474个固定周期，Clean及10/15/20/25/30/35/40 dB共享同一周期边界和标签顺序。正式评估读取服务器原MAT，不使用float32导出NPZ入口。
- 347条Final-Holdout没有训练、选模、测评或导出；本表是开发集成绩。
- 三种方法均使用种子42/43/44；每次50轮、1200次优化更新；Adam学习率0.001、batch32、weight_decay=0。
- Clean/加噪CE各占0.5；沿用V1 M1的整记录、逐相RMS高斯加噪和七档SNR抽样。相同种子/轮次使用相同噪声与minibatch顺序；未实施按故障周期计算噪声功率的修正。
- 输入：完整电周期五相物理电流→4096点插值→频率模块→极值中心化/低电流分支→128点插值→原CNN。
- 权重选择仅使用Source-Val：Clean在全程最佳值1个百分点以内，再选固定10/20/30 dB源噪声验证均值最高者；平分时依次选较高Clean、较早轮次。
