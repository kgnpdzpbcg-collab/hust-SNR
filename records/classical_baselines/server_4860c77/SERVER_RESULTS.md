# SVM、RF、ResNet1D服务器实验记录

分支：`research/classical-baselines-v1`。运行提交：`4860c7766a58cd1f0ffb9b3d92195edb3a3ecc25`，原基线实现来自`ccd9cf4`。日期：2026-10-13。

## 数据与训练协议

- 仿真训练34个文件、738个周期；仿真验证15个文件、302个周期；实测Dev为原88个文件编号、每条件2474个周期。训练和验证原始文件不重叠。
- 标签采用原冻结逐周期元数据，六类周期数1106/307/297/298/237/229为实测Dev分布。所有方法与历史模型共用周期边界、标签和顺序。
- 训练噪声为10/15/20/25/30/35/40 dB，沿用整记录每相RMS的高斯增强；源验证为Clean和固定0/5/10/20/30 dB。
- 实测评估包含Clean、作者10–40 dB七档，以及既有作者10 dB噪声残差放大形成的0/5 dB。后两档是合成压力条件，并非新采集的实测噪声。347个最终保留编号未读取。
- 三种方法全部运行42/43/44，不删除低分种子。源验证选超参数/轮次，实测Dev仅在模型选择后推理。
- SVM与RF：完整五相4096点周期进行MD归一化，逐相提取8个时域统计、前8阶谐波幅值、前4阶复系数实部/虚部，共120维。使用Clean加7次冻结源增强，共5904个训练视图；不是5904个新原始文件。SVM的StandardScaler只在这些源训练视图拟合。
- SVM候选C=0.1/1/10、RBF及gamma=scale；RF为300棵树、叶子最少样本1/3、max_features=sqrt。均在源验证选择，未扩大搜索。
- ResNet：同V5的MD归一化及128点采样，无频域滤波；六个残差块、通道32/64/128、全局平均池化及128→6分类头，共241702参数。50轮、batch32、Adam lr=0.001、WD=0；损失为Clean/Noisy平均交叉熵。每轮24次更新，每种子1200次更新。
- 选模：Clean Macro-F1在源Clean最高值1个百分点以内，然后最大化五档噪声源验证平均Macro-F1，并列按Clean及候选顺序/较早轮次确定。
- 原始文件相同，但SVM/RF固定8个训练视图与神经网络50轮刷新噪声的优化过程不同；人工特征、主干与特征维度也不同。

### 文件索引说明

一个原始文件可同时包含故障前健康周期和故障后故障周期，因此[本轮文件索引](results/reports/DATA_FILE_INDEX.csv)按文件与类别分行，并给出周期数、起止秒数和实际文件路径。例如`S-1000-0-1-O.mat`的17个健康周期为0.100–0.440秒，22个标签1故障周期为0.540–0.980秒。训练一直采用冻结逐周期标签；旧式单行文件索引不作为标签输入。本轮没有修改旧报告或数据标签。

导出索引时先后发现旧路径缺失及“单文件单标签”假设不成立；修正导出统计后再次复核完成，模型未重训。
