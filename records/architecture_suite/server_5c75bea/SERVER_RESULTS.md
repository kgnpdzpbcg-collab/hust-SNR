# HUST九模型结构对照服务器记录

日期2026-10-14。分支`research/architecture-sweep-v1`。运行原代码提交`5c75bea67ffb1dd7730398193aba8b3498382e82`。九模型、三个种子42/43/44，共27次50轮训练和270组十条件实测Dev评估。原模型、数据处理、训练脚本及冻结配置未修改。

## 模型与实际参数量

| 方法 | 频域前端 | 主干 | 参数量 |
|---|---|---|---:|
| v5_w | NA-HSF | 32/64/64，原三层卷积 | 63213 |
| v5_wd_plain | NA-HSF | 加宽＋64通道双卷积，无shortcut | 88045 |
| v5_wd_res | NA-HSF | 同双卷积，增加identity shortcut | 88045 |
| v5_w_ms | NA-HSF | 加宽＋7/15/31多尺度Stem | 63693 |
| v5_wd_plain_ms | NA-HSF | 多尺度＋双卷积，无shortcut | 88525 |
| v5_wd_res_ms | NA-HSF | 多尺度＋双卷积＋identity shortcut | 88525 |
| resnet_lp3 | LP3 | 原ResNet主干 | 241702 |
| resnet_lp4 | LP4 | 原ResNet主干 | 241702 |
| resnet_nahsf | NA-HSF | 原ResNet主干 | 241743 |

前六模型使用704→50→6分类器，后三模型使用原ResNet的GAP128→6分类器。频域处理在原始4096点周期上进行，随后仅一次MD归一化及128点重采样。ResNet包装器直接调用stem/layers/pool/classifier，未重复执行其原forward中的归一化。

多尺度分支7/15/31、通道8/12/12，SAME卷积后裁剪[7:120]，统一113点后池化为56点；后续两层输出64×11。与原偶数16点卷积存在半个采样点的中心差，卷积核和参数量也不相同。

## 冻结数据和训练配置

- 仿真训练34个文件、738周期，仿真验证15个文件、302周期；文件集合无交集。输入、逐周期标签和切分完全沿用既有版本。
- 每轮整记录逐相RMS高斯噪声，训练档位10/15/20/25/30/35/40 dB。同seed/epoch共用原噪声函数；首轮数组SHA与历史ResNet一致。
- 每种子50轮、batch32、Adam lr0.001、weight_decay0，每轮24次更新。Clean/Noisy同批次前向，损失为0.5 CE(Clean)+0.5 CE(Noisy)。总计1350轮、32400次更新。
- 源验证为Clean和固定0/5/10/20/30 dB，各302周期。Clean F1距离本运行最高值≤1个百分点，在合格轮次中最大化五档噪声平均Macro-F1，并列按Clean更高、epoch更早确定。
- 实测Dev为原88个文件编号、每条件全部2474周期；Clean、作者原10–40 dB七档以及既有10 dB噪声残差放大生成的0/5 dB。0/5 dB是合成压力条件，不是新采集的实测噪声。
- 六类周期数1106/307/297/298/237/229，所有模型、种子与条件保持相同标签及顺序。实测Dev不用于训练或选epoch。源Test、347个最终保留编号未评估。
- 旧V5/ResNet结果只读复用。其他原实验、全部旧种子及图像未重训、替换或覆盖。

## 初始化和结构控制

三个种子的`v5_wd_plain`/`v5_wd_res`、`v5_wd_plain_ms`/`v5_wd_res_ms`分别满足参数量和初始可学习权重SHA完全一致；两对只有不带参数的identity shortcut开关不同。三个新ResNet的主干初始化逐张量相同，参数摘要与历史未滤波ResNet初始权重相同。实际SHA见[预检记录](PREFLIGHT.json)。

加宽、多尺度及ResNet门控对照的参数量并非都相同；所有模型各自进行相同源验证选模。

## 执行、核验及文件状态

服务器`wang@172.28.128.160`、RTX 5070 Ti、既有uv/PyTorch 2.14.1+cu130环境。四个独立工作进程、每进程四个CPU线程，共享同一GPU；27次训练、270组推理及汇总墙钟209.972秒（不含独立核验及上传）。各次完整命令、进程状态和耗时见[RUN_STATUS.json](RUN_STATUS.json)。

- 服务器25项原测试、九模型CLI smoke、shell语法检查及27组真实GPU首批次梯度检查通过。
- 1350轮训练历史完整、损失有限；27组源选模独立重算，162组源验证及270组目标预测完全重放。混淆矩阵、六类F1/Recall、误报/漏报及90组均值/标准差独立重算。
- 最佳权重BN批次计数与epoch×24相同，推理前后所有模型状态张量相同。2196个旧文件SHA保持不变。
- 初次核验遗漏正式推理的`fix_randomness`设置，默认CUDA开关为非确定性、cudnn TF32允许；10 dB的`v5_w_ms`种子44及`v5_wd_res_ms`种子43分别有1个周期argmax不同。权重和数据相同，恢复原确定性算法及关闭TF32后全部270组目标预测完全一致。诊断只是核验设置检查，不替换正式预测。
- 核验记录的诊断相对文件引用已纠正，数值及模型没有变化；首份归档保留在服务器。修正前后SHA见[引用修正记录](EXPORT_REFERENCE_CORRECTION.json)。
- 文件索引按“文件＋类别＋时间段”分行，故障前健康及故障后状态分别计数；标签仍来自原冻结周期元数据。
- 模型PT、原始MAT/电流、NPZ和环境均留在服务器。发布原配置、日志、指标、预测标签、哈希和客观记录。
