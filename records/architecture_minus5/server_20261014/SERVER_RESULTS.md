噪声为作者10 dB与Clean配对残差×`10^0.75`；−5 dB是原整记录每相的SNR，不意味着每个截取周期都有精确−5 dB。

使用原训练代码快照中的读取器和模型：按原规则合并重复时间戳，按同一Clean周期边界插值为五相4096点输入，再由模型执行其原谐波前端、MD归一化和4096→128点重采样。没有额外滤波、归一化或调整阈值。原推理批大小128；确定性算法开启，CUDA矩阵及cuDNN的TF32关闭，cuDNN确定性开启。
