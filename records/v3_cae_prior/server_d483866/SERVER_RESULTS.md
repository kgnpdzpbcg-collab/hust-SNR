实验日期：2026-10-12。实际运行提交：`d48386699ce0dca2d39d6c0dfabaa75ad064ac6a`，分支`research/cae-lowpass-prior-v3`。四方法×三种子×50轮训练、96次Target-Dev评估及独立核验完成。模型代码和冻结超参数没有修改。

## 配置与范围

服务器GPU：NVIDIA GeForce RTX 5070 Ti；Python 3.12.3，PyTorch 2.14.1+cu130，NumPy 2.5.3。复用既有uv/PyTorch环境，未安装依赖。四组并发，每组4个CPU线程，严格确定性运行、关闭TF32。

- Source-Train：34条记录/738周期；Source-Val：15条记录/302周期。数据划分、完整电周期、噪声随机数流和选模规则复用冻结V2代码。
- Target-Dev：88条唯一实测记录/2474固定周期，Clean＋10/15/20/25/30/35/40 dB使用同一边界和标签顺序。正式评估读取原MAT；347条Final-Holdout未读取或评估。
- 种子42/43/44；Adam lr=0.001、batch32、50轮、每模型1200次优化更新；weight_decay=0。
- 输入：五相原始电流→4096点周期插值→频率模块→MD极值中心化/低电流相保护→128点插值→原Encoder＋分类头。
- 沿用整记录、逐相RMS Gaussian加噪，SNR从七档随机抽取。Clean/Noisy CE各占0.5；带Decoder组额外加入平均自身重构MSE，lambda_rec=1。
- 重构目标是各视图自身经过频谱整形和MD后的输入，目标detach；不是含噪视图重构Clean。Decoder仅用于训练和本轮额外损失核验，正式分类推理不执行Decoder。
- 先验门控：DC=1；前三阶初始增益约0.9900，高阶约0.0100；128个共享残差参数，sigmoid(prior_logit＋8×residual)，不放大、不引入额外频谱相位旋转。
- 原论文Decoder尺寸存在歧义，本仓库使用转置卷积及对称填充对齐长度；这是声明的近似实现。未加入原论文深度度量学习Loss3。
- 权重仅按Source-Val选取：Clean距全程最佳不超过1个百分点，选固定10/20/30 dB源域带噪Macro-F1均值最高者，平分后按较高Clean、较早轮次。
- 相同种子的CNN初始化及首轮源噪声输入哈希与已完成V2相同。
