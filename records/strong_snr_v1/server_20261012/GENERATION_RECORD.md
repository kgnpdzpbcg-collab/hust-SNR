# 5/0 dB强噪声数据生成记录

- 仿真：按整条记录、每相RMS校准高斯噪声；实测：按用户选择放大作者已有10 dB噪声。
- 两档新实测均为本项目派生，不是作者发布的新档位；复用10 dB噪声样本，不视为独立噪声采集。
- 原训练/验证/最终保留划分不变。所有新MAT在服务器生成；旧模型未重训，旧权重与选模未改变。

## 原训练和验证噪声

原训练每轮为每条仿真记录随机抽取10/15/20/25/30/35/40 dB的高斯噪声，同时使用干净波形。原验证使用干净波形和固定10/20/30 dB高斯噪声。

扩展配置列出训练0/5/10/15/20/25/30/35/40 dB，以及验证0/5/10/20/30 dB。这里只生成5/0 dB数据，没有把新配置注入旧V4训练入口。

## 实测生成公式

`noise10 = author_snr10 - clean`

`new = clean + noise10 * 10**((10 - desired_snr)/20)`

5 dB放大系数1.778279410038923；0 dB放大系数3.1622776601683795。只改变五相电流，时间和角速度列逐值不变；保留原始10031行和重复时间戳，不先归一化、切窗或降采样。

仿真保持10000×6的I_We字段；实测保持10031×7的I_noisy字段，均为float64。四个缺少Excel标签的仿真原文件未纳入，使用原标注明确的59条仿真记录。

## 数值与复现核验

- 8项单元测试通过，包括不同相幅值、故障相近零、非均匀作者噪声、错误参考档位、固定随机数与MAT重新读取。
- 998个生成文件全部重新读取并复算每相整记录SNR，最大差6.75016e-14 dB。
- 939个原MAT的完整字节指纹不变；12份旧V4权重不变。
- 初次严格比对发现MAT列连续布局与旧读取器行连续布局的求平均末位差；SNR核验通过，噪声矩阵最大差2.13e-14。统一为旧代码的行连续顺序后，仅重新生成118个仿真文件，880个实测文件不变。
- 修正后，15个源验证编号×两档的原分辨率噪声矩阵与原calibrated_noise函数相同随机流计算结果逐数值完全一致。
- 文件指纹核对本次导出字节；矩阵指纹核对确定性数值，MAT头部导出时间不参与矩阵指纹。
