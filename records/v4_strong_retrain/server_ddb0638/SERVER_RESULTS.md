## 数据文件、用途和处理

- 34个仿真MAT用于训练，切成原738个周期；每轮每条记录随机抽取九档之一，重新生成整记录、每相RMS校准的高斯噪声。每批同时使用对应Clean和noisy周期。
- 15个仿真MAT用于验证，使用原302个周期；Clean和五档噪声分别计算指标，不更新模型参数。
- 验证0/5 dB读取之前已保存的30个仿真MAT；10/20/30 dB按原固定随机流生成。五档噪声验证分数平均后参与选模。
- 已生成的训练编号0/5 dB静态MAT不作为本轮训练噪声输入：训练保留每轮重新加噪，0/5 dB参与随机抽样。
- 实测评估读取原88个编号，每条件2474个周期；Clean及0/5/10/15/20/25/30/35/40 dB，共10个条件、120组模型评估。
- 实测0/5 dB沿用已生成的数据：Clean+(作者10dB−Clean)×10**((10−SNR)/20)。未重新生成噪声。
- 原10个仿真保留编号、347个实测最终保留编号没有进行模型评估。实测标签和成绩不参与训练或选模。
- 原周期边界、标签、完整重复记录处理保持不变：先取原完整周期并插值到4096点，再滤波、MD归一化，形成五相×128点CNN输入。
- 每个种子每轮738个Clean周期＋738个noisy周期，每轮24次更新，50轮共1200次更新；12组模型共14400次更新。新增噪声没有增加原始记录数或优化器更新预算。

每条件实测周期类别数量：Healthy 1106、OUS(A) 307、OLS(A) 297、OP(A) 298、OUS(A)&OUS(B) 237、OLS(A)&OP(C) 229。
