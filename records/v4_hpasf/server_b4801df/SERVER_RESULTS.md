## 代码与运行配置

原提交在真实训练批次的CUDA预检阶段失败，尚未开始正式训练：`median(dim=-1)`因返回索引不支持严格确定性。运行提交把12–30阶的19个功率值稳定排序后取第10个，保持原中位数公式、梯度隔离和严格确定性。新增CPU重复功率及CUDA严格确定性对照测试。详见[原预检记录](prior_preflight/UPSTREAM_PREFLIGHT_FAILURE.json)。

- 四组：lowpass3、lowpass4、static4、hpasf；各随机种子42/43/44。
- 四组CNN均25620参数；static4/hpasf另有1个可学习频率标量，合计25621。
- 50轮、batch32、Adam lr=0.001、weight_decay=0，损失`0.5*CE(clean)+0.5*CE(noisy)`；不含解码器、重构或一致性损失。
- 训练噪声仍为代码给源仿真整记录按相RMS生成的高斯噪声，每条记录每轮从10/15/20/25/30/35/40 dB抽取一档。
- 只用源仿真Val Clean及固定10/20/30 dB选择权重，实测不参与梯度更新或权重选择。
- 四组并发，各组内三个种子顺序执行；每进程CPU线程4；FP32、严格确定性、TF32关闭。
