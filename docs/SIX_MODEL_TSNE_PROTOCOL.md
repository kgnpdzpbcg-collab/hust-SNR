# 六模型固定权重特征可视化协议

比较A′无滤波、三阶低通、四阶低通、固定α=0.5、V5和Xu-Full。Xu-Full只有42/43/44三个种子，因此全部模型统一使用这三个种子，不按模型成绩挑选种子。数据为固定88个实测Dev编号的全部2474周期，条件Clean及10 dB。图中六类使用相同颜色与符号，类别数量1106/307/297/298/237/229保持原始比例，不删去重叠点。

每个模型使用其原源验证最佳权重。编码器输出展开352维，作为主图；分类器最后Linear前50维隐藏特征，作为补充图。Xu-Full的DML作用于352维层，但六模型都具有这两层。最后六类logits不作为特征。提取后需通过原分类头重放预测，与已保存正式预测完全一致；全部状态张量保持不变，不重新训练或选模。

两层、两条件、三种子、六模型共72组投影，输出12张六面板图。每组独立拟合，输入为对应模型的全部周期特征；不能将不同神经网络的未对齐神经元直接混在一起联合降维。

固定处理：一次无标签全局RMS尺度变换，保留欧氏几何；PCA降至50维后t-SNE。各组使用相同二维高斯初始坐标、随机状态20261013、perplexity30、early_exaggeration12、learning_rate auto、1500步预算、Barnes-Hut angle0.5。标签不参与PCA/t-SNE拟合，权重、噪声、样本、随机参数不按绘图效果调整。

原空间指标在PCA之前计算，包括欧氏轮廓系数、按六类等权平均的轮廓系数、5NN同类率。5NN排除来自同一原始MAT记录的全部周期，按六类等权统计，避免相邻/近重复周期提高局部纯度。另保存t-SNE邻域可信度k=15、KL、迭代数和PCA方差保留率。5NN只用于事后几何分析，不是新分类模型或新的测试成绩。

二维投影可能改变距离和簇形状。各模型坐标系、簇位置和绝对距离不同，不能根据“更紧/更远”直接判断模型更好；轮廓系数和5NN同类率也不等于分类准确率。图中F1仍来自原最佳权重的实际分类预测，S为原空间宏平均轮廓系数。

特征提取、降维在服务器既有环境运行。原始352/50维数组仅保存在服务器，绘图在本地复用已有`.cache/figure_runtime` Matplotlib缓存；不新建PyTorch环境或安装依赖。发布代码、二维坐标、指标、配置、SHA及600dpi PNG/字体嵌入PDF，不发布原始电流、权重或高维NPZ。347个Final-Holdout不读取、不评估。

入口为`scripts/six_model_tsne.py`及`scripts/plot_six_model_tsne.py`，配置为`configs/six_model_tsne_v1.json`。各阶段使用独立新输出目录并拒绝覆盖。正式完成、预测重放及图像检查状态另外记录；本协议本身不代表已运行。
